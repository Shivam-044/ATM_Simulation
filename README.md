# ATM Simulation Engine 🏦

A professional-grade terminal application demonstrating a decoupled **Package Architecture** and reliable financial state management. This system prioritizes security, user experience, and clean, modular code.

## ⚙️ Core Logic Features
- **Input Validation:** Robust error handling prevents crashes from non-numeric inputs.
- **Business Rules:** Implements a strict $500.00 daily withdrawal limit to simulate real-world banking constraints.
- **Precision Formatting:** Utilizes currency-grade string formatting to ensure all balances and transactions remain professional.
- **Transaction Ledger:** Tracks all account activities with a dedicated mini-statement service.

## 🛠 Project Structure
- `atm_logic.py`: The **Service Layer**—encapsulates all mathematical operations, state management, and business logic.
- `main.py`: The **Presentation Layer**—manages the user interface, interaction loops, and input orchestration.

2. Navigate to the project directory:
